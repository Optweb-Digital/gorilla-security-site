AI Implementation Approaches
============================

Purpose
-------
Use this document as an index of significant implementation tasks assisted by AI tools such as ChatGPT, Gemini, or Grok.

For each task:
1. Create a separate dated entry or copy `05-ai-implementation-log-template.md`.
2. Record the objective and tool used.
3. Summarize the prompt and approach.
4. Describe the steps actually followed.
5. Record errors and how they were resolved.
6. Explain how the result was tested.
7. Record lessons learned.

Suggested entries for this project
----------------------------------
- Installing and verifying Docker Desktop on Windows.
- Starting WordPress with Docker Compose.
- Accessing WordPress through localhost.
- Cloning the repository with GitHub Desktop.
- Committing and pushing documentation.
- Troubleshooting GitHub authentication.
- Creating branches and pull requests.
- Practising merge conflict resolution.

Only record steps you actually performed. Clearly distinguish AI suggestions from changes tested and verified.
