# Copy

Owner: content writer. One file per page: `home.md`, `contact-us.md`, `service-{slug}.md`.

Structure each file by section, using the pattern slugs from `docs/sitemap.md` as headings:

```markdown
## hero
- eyebrow:
- heading: (wrap accent words in [[double brackets]])
- lead:
- button:

## faq
1. Q: … / A: …
```

Rules:
- Real copy only — agents use `[[TODO: copy]]` where this folder has nothing and never invent facts
  (prices, phone numbers, certifications, legal text).
- SEO title ≤ 60 chars and meta description ≤ 155 chars at the top of each page file.
- Outstanding from Figma: "Why us" steps 02–06 and FAQ answers 01, 03–08.
