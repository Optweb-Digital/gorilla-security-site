WordPress Docker and Git End-to-End Training
=============================================

This repository documents a local WordPress development environment using Docker, plus Git and GitHub collaboration workflows.

Documentation included
----------------------
- `documents/01-windows-prerequisites-and-installation.md` — Docker Desktop, Git, and GitHub Desktop installation.
- `documents/02-wordpress-docker-local-setup.md` — run WordPress locally using Docker Compose.
- `documents/03-github-desktop-workflow.md` — clone, commit, push, fetch, and pull.
- `documents/04-git-five-concepts.md` — commit, push/pull, pull requests, conflict management, and branching.
